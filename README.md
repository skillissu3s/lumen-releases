# Lumen — downloads

Installers for [Lumen](https://github.com/skillissu3s/lumen), a personal
productivity app: tasks, a time-blocking calendar, docs and chat, stored as plain
text in your own GitHub repository.

**[Download the latest version →](https://github.com/skillissu3s/lumen-releases/releases/latest)**

| | |
|---|---|
| Windows | [Lumen-Setup.exe](https://github.com/skillissu3s/lumen-releases/releases/latest/download/Lumen-Setup.exe) |
| macOS (Apple silicon and Intel) | [Lumen.dmg](https://github.com/skillissu3s/lumen-releases/releases/latest/download/Lumen.dmg) |
| Linux | [Lumen.AppImage](https://github.com/skillissu3s/lumen-releases/releases/latest/download/Lumen.AppImage) · [lumen.deb](https://github.com/skillissu3s/lumen-releases/releases/latest/download/lumen.deb) |

The app updates itself: on Windows and the Linux AppImage new versions download in
the background and install when you restart Lumen. On macOS and with the .deb, the
app tells you when a new version is out.

The installers aren't code-signed yet. On Windows choose *More info → Run anyway*
the first time; on macOS use *System Settings → Privacy & Security → Open Anyway*.

This repository only holds release files; it is published automatically.
